# 🌤️ Atmos by Tamj

A modern weather dashboard built with React, TypeScript, and Vite.

_Dashboard cuaca modern yang dibangun menggunakan React, TypeScript, dan Vite._

## ✨ Features / Fitur

- **Weather Dashboard** — Explore weather information through a modern dashboard interface.

  _Melihat informasi cuaca melalui antarmuka dashboard yang modern._

- **City Search** — Search for weather information by city.

  _Mencari informasi cuaca berdasarkan nama kota._

- **Temperature Conversion** — Switch between Celsius and Fahrenheit.

  _Mengganti satuan suhu antara Celsius dan Fahrenheit._

- **Favorite Cities** — Save favorite cities for quick access.

  _Menyimpan kota favorit agar mudah diakses._

- **City Comparison** — Compare weather information across multiple cities.

  _Membandingkan informasi cuaca dari beberapa kota._

- **Weather Map** — Explore weather information visually.

  _Menjelajahi informasi cuaca melalui tampilan peta._

- **Weather Charts** — Visualize weather information through charts.

  _Melihat visualisasi informasi cuaca dalam bentuk grafik._

## 🛠️ Tech Stack / Teknologi

- **React** — A library for building user interfaces.

  _Library untuk membangun antarmuka pengguna._

- **TypeScript** — JavaScript with static typing.

  _JavaScript dengan sistem tipe statis._

- **Vite** — A fast development server and build tool.

  _Server pengembangan dan alat build yang cepat._

- **Tailwind CSS** — A utility-first CSS framework.

  _Framework CSS yang menggunakan utility classes untuk mengatur tampilan._

- **ESLint** — A tool for identifying code quality issues.

  _Alat untuk mendeteksi masalah kualitas kode._

## 🚀 Getting Started / Cara Menjalankan

Follow these steps to run Atmos on your local machine.

_Ikuti langkah-langkah berikut untuk menjalankan Atmos di komputer lokal._

1. Clone the repository / Salin repository:

   ```bash
   git clone https://github.com/Tamj-delcroix/atmos-by-tamj.git
   ```

2. Navigate to the project folder / Masuk ke folder project:

   ```bash
   cd atmos-by-tamj
   ```

3. Install dependencies / Instal dependensi:

   ```bash
   npm install
   ```

4. Start the development server / Jalankan server pengembangan:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

   _Buka alamat lokal yang ditampilkan di terminal._

## 🧪 Quality Checks / Pemeriksaan Kualitas

Run ESLint to check code quality.

_Jalankan ESLint untuk memeriksa kualitas kode._

```bash
npm run lint
```

Build the application for production.

_Build aplikasi untuk penggunaan produksi._

```bash
npm run build
```
